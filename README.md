# Bundelkhand FM App

## Overview
Bundelkhand FM is a web‑based multimedia application designed to provide users with easy access to live radio streams, on‑demand audio content, and community features from the Bundelkhand region. Built with modern front‑end technologies, the app delivers a responsive, visually appealing interface that works seamlessly across desktop and mobile browsers. It leverages lightweight HTML, vanilla JavaScript, and Tailwind CSS to create a fast, maintainable experience while hosting the site on GitHub Pages for free, public distribution.

## Features
- **Live Radio Streams** – Stream local and regional FM stations in real time with minimal latency.  
- **On‑Demand Audio Library** – Browse a curated collection of podcasts, music playlists, and news segments.  
- **Responsive Design** – Fully adaptive layout that adapts to smartphones, tablets, and desktops.  
- **Customizable UI** – Tailwind‑styled components allow easy theming and branding adjustments.  
- **User Authentication** – Simple login system for personalized playlists and saved stations.  
- **Search & Filter** – Fast search functionality with filters for genre, language, and station type.  
- **Social Sharing** – One‑click sharing of current tracks and playlist links via major platforms.  

## Technology Stack
- **Frontend:** HTML5, JavaScript (ES6+), Tailwind CSS  
- **Hosting:** GitHub Pages (static site deployment)  
- **Version Control:** Git & GitHub repositories
